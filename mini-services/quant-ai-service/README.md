# Quant AI Service (TradeAI Phase 3)

Microserviço institucional em Python FastAPI gerenciado via `uv`:
- **Split Conformal Prediction**: Previsão probabilística com intervalos de confiança calibrados e garantias matemáticas de cobertura (95%).
- **Adversarial Signal Robustness**: Testador adversarial $\epsilon$-bounded com Wilson upper confidence bound para blindagem contra spoofing e ruído de microestrutura no livro L2.
- **Multimodal Chart Vision**: Integração com Google Gemini 2.5 Flash para análise semântica e visual de candlesticks.
